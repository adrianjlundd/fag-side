# TDT4195 · visdat

Les først denne fila og PROGRESS.md. Kontroller git-status og lokal graf før du fortsetter fra første åpne punkt. Oppdater arbeidsloggen når en større del er ferdig.

- Nettstedet ligger i visdat/. Bruk statisk HTML, CSS og vanlig JavaScript, relative URL-er og norsk bokmål. Repoets Pages-sti er /fag-side/.
- Avgrens H26 med course_information.txt og begge forelesningsplanene. Knytt konkrete mål til en kilde eller merk dem som utledet. Oppgi både oppgavenummer og PDF-side.
- Søk i lokal Graphify over stdio. Slå opp konkrete figurdetaljer, matriser og svar i original-PDF-ene. Bruk NoAnswers til ordlyden og årgangens svarfil til fasitkontroll.
- Bevar stabile oppgave-ID-er i visdat/kilder/eksamen.json. Kapitler åpner med Eksamensfokus, forklarer konvensjoner og avslutter med trening og skjult svar. Skille mellom originalreferanse, kontrollert fasit og eget løsningsforslag skal være synlig.
- Test nettstedet over HTTP under prosjektstien, med tastatur og smal skjerm. Publiserbare filer er rotens index.html og visdat/. Hold arbeidslogg, graf og originalmateriale utenfor publiseringsartefakten. Commit, push og publisering krever bestilling.
